# Minha Rotina

Aplicativo pessoal de gestão de rotina diária, feito especialmente para ajudar a organizar o dia com as crianças e a casa, usando o método Fly Lady.

## Como usar

1. Acesse o site: **https://larissamoufa.github.io/minha-rotina/** (após ativar o GitHub Pages)
2. No iPhone (Safari): toque em **Compartilhar** → **Adicionar à Tela de Início**
3. Pronto! O app fica na sua tela inicial como um aplicativo nativo.

## Funcionalidades

- **Rotina Completa**: sequência do dia inteiro com horários
- **Crianças**: lista das coisas que não pode deixar de fazer
- **Casa**: não negociáveis do método Fly Lady + zona do dia
- Checkboxes que salvam o progresso do dia
- Destaque da tarefa atual
- Barra de progresso
- Foco do dia e zona da casa automáticos conforme o dia da semana

## Como ativar o GitHub Pages

1. Vá em Settings do repositório
2. Pages
3. Source: Deploy from a branch
4. Branch: main / root
5. Save

Em alguns minutos o site estará no ar.

Feito com carinho para ajudar no dia a dia.
